# 罫線素片全列挙プロジェクト

JIS X 0208 と Code Page 437 の罫線素片を盤面に過不足なく結合する配置を全列挙します。

## 成果

### JIS X 0208 罫線素片 32 字 × 8×4 盤面

全 **37 代表解** を発見（D4 群による回転・反射と種類ラベル置換を同一視）

- **単結合解**: 25 個（接続エッジをたどると全タイルに到達可能）
- **非単結合解**: 12 個（2つ以上の分離した部分を含む）

詳細は `gallery.html` および `solutions_summary.txt` を参照。

## 重要な設計原則

### タイルは固定向き
- 各罫線素片は決まった向きで存在する
- タイルを回転させることはできない
- 盤面の対称性を考察する際、盤面全体（すべてのセルの sides）を D4 変換し、変換後の各セルが実在する罫線素片に対応するかを確認する
- 対応する素片が存在しなければ、その変換は無効

### 接続定義
- **接続成立**: 隣接セルの共有辺が 0 でなく、かつ一致する
- **0-0 は許容**: 両方接続なしだが、これは「接続」ではない

### 単結合性
- 「接続成立」のエッジをたどる BFS で、全タイルに到達可能なら「単結合」

## 使い方

### 前提
- Python 3.7+

### 基本的な実行

```bash
# 8×4 で全代表解を列挙（数分かかります）
python explore.py --rows 4 --cols 8 --tiles jis32.json --max 0

# 最初の1解だけ見つける
python explore.py --rows 4 --cols 8 --tiles jis32.json --max 1

# 結果を ASCII アートで表示・検証
python render_solution.py

# HTML ギャラリーとテキスト一覧を生成
python gallery_generator.py
```

### コマンドラインオプション

```
--rows R       盤面の行数（デフォルト: 4）
--cols C       盤面の列数（デフォルト: 8）
--tiles FILE   タイル定義 JSON ファイル（必須）
--max N        見つける代表解の上限（0 = 全部、デフォルト: 1）
```

## ファイル構成

### コア
- `explore.py` - バックトラック全探索エンジン
- `jis32.json` - JIS X 0208 罫線 32 字の定義
- `jis8.json` - テスト用（角パーツのみ）

### ユーティリティ
- `render_solution.py` - 解の検証と ASCII アート出力
- `gallery_generator.py` - HTML/テキスト出力生成

### 出力
- `solution_1.json` ~ `solution_37.json` - 各代表解（JSON）
- `gallery.html` - HTML ギャラリー（ブラウザで表示）
- `solutions_summary.txt` - 全解の ASCII アート（テキスト形式）

## 技術詳細

### sides の表現
各タイルの各辺は [N, E, S, W] で表現され、値は：
- `0`: 接続なし
- `1`: 細線接続（JIS）
- `2`: 太線接続（JIS）

Code Page 437 では：
- `1`: 一重線
- `2`: 二重線

### 正規化（canonicalization）
1. 完全な盤面が出来上がったら、D4 群の 8 変換を適用
2. 各変換について、すべてのセルの sides が実在する罫線素片に対応するか確認
3. 対応しない変換は除外
4. 種類ラベル置換（1↔2）も追加適用
5. 得られたすべての符号の中から辞書順最小を「代表符号」とし、ユニーク判定に使用

## よくある質問

**Q: タイルを回転させて置けないのか？**
A: いいえ。各タイルは固定向き。代わりに盤面全体を回転・反射させ、その際に対応する素片が実在するかチェックします。

**Q: 単結合と非単結合の違いは？**
A: 「接続成立」のエッジをたどる DFS/BFS で、全タイルに到達できるなら単結合。そうでなければ 2つ以上の分離した部分を含む。

**Q: 種類（細↔太）の置換は何か？**
A: 細線と太線のラベルを入れ替えても盤面の構造は変わらないので、これを同一視。
